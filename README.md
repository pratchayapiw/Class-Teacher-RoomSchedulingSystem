# ระบบตารางสอน กลุ่มสาระการเรียนรู้ภาษาต่างประเทศ

โรงเรียนวรราชาทินัดดามาตุวิทยา · ภาคเรียนที่ 2 ปีการศึกษา 2569

เว็บแอปสำหรับจัดและดูตารางสอน ตารางเรียน และตารางการใช้ห้อง ครูทุกคนเปิดดูจากลิงก์เดียวกันได้ และเห็นข้อมูลชุดล่าสุดตรงกันทุกเครื่อง

- **หน้าเว็บ** ใช้ GitHub Pages (ฟรี ไม่ต้องติดตั้งหรือ build)
- **ฐานข้อมูล** ใช้ Supabase (ฟรี) บันทึกอัตโนมัติ อัปเดตทุกเครื่องทันที และเก็บประวัติย้อนหลัง 200 เวอร์ชัน

## ความสามารถ

| เมนู | ใช้ทำอะไร |
|---|---|
| ตารางครู / ตารางเรียน / ตารางห้อง | ลากเพื่อย้ายหรือสลับคาบ สอนร่วมหลายครูใน 1 คาบ ตรวจคาบชนอัตโนมัติ สรุปท้ายตาราง |
| ภาพรวมรายวัน | ดูครูทุกคนในวันเดียว และหาครูที่ว่างสอนแทน |
| สรุปข้อมูล | สรุปรายคน รายชั้น รายห้อง: คาบสอน กิจกรรม ค้นคว้าอิสระ และคาบร่วมกับ ENG1/ENG2 |
| สอนแทน / แลกคาบ | บันทึกครูลา จัดผู้สอนแทน (กดให้จัดอัตโนมัติได้) แลกคาบ ติดตามคาบค้างตอบแทน คัดลอกใบแจ้งไปส่งใน LINE |
| จัดตารางอัตโนมัติ | จัดให้ครูคนเดียวหรือหลายคน ตามเงื่อนไขที่ตั้งไว้ ดูตัวอย่างก่อนกดใช้ |
| พิมพ์ / ดาวน์โหลด | พิมพ์หรือบันทึกเป็น PDF (A4 แนวนอน มีหัวกระดาษ สรุป และช่องลงนาม) ดาวน์โหลดเป็น Excel หรือไฟล์สำรอง .json |
| จัดการข้อมูล | ครู รายวิชา ชั้น ห้อง เพิ่มทีละหลายรายการได้ ตั้งค่าหัวกระดาษและรายชื่อผู้ลงนาม |

ทุกการแก้ไขกด **เลิกทำ** ได้ (Ctrl+Z)

## ติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### ขั้นที่ 1 · สร้างฐานข้อมูล Supabase

1. สมัครหรือเข้าสู่ระบบที่ <https://supabase.com> แล้วกด **New project** ตั้งชื่อเช่น `timetable` และเลือก Region **Southeast Asia (Singapore)**
2. ไปที่ **SQL Editor → New query** วางเนื้อหาทั้งหมดของไฟล์ `supabase/schema.sql` แล้วกด **Run**
3. เพิ่มบัญชีครูที่แก้ไขตารางได้
   - ไปที่ **Authentication → Users → Add user → Create new user** ใส่อีเมลและรหัสผ่าน แล้วติ๊ก *Auto Confirm User*
   - กลับไปที่ **SQL Editor** แล้วรันคำสั่งนี้ (เปลี่ยนเป็นอีเมลจริง) ทำซ้ำได้ทุกคนที่ต้องการให้แก้ไขได้

     ```sql
     insert into public.editors (email, name) values ('teacher@school.ac.th', 'ครูปรัชญา');
     ```
4. (แนะนำ) ไปที่ **Authentication → Sign In / Providers → Email** แล้วปิด **Allow new users to sign up** เพื่อไม่ให้คนนอกสมัครเอง ถึงจะสมัครได้ก็แก้ไขไม่ได้ ถ้าไม่มีชื่อในตาราง `editors`
5. ไปที่ **Project Settings → API** แล้วคัดลอก 2 ค่านี้
   - **Project URL**
   - **anon public** key (ห้ามใช้ `service_role`)

### ขั้นที่ 2 · ใส่ค่าในไฟล์ `config.js`

```js
window.APP_CONFIG = {
  supabaseUrl: 'https://xxxxxxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOi...',
  termId: '2569-2'
};
```

anon key เปิดเผยในหน้าเว็บได้ เพราะสิทธิ์การแก้ไขถูกควบคุมด้วย Row Level Security ในฐานข้อมูล

### ขั้นที่ 3 · เผยแพร่บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `timetable`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (**Add file → Upload files**) หรือใช้คำสั่ง

   ```bash
   git init && git add . && git commit -m "ระบบตารางสอน"
   git branch -M main
   git remote add origin https://github.com/<ชื่อบัญชี>/timetable.git
   git push -u origin main
   ```
3. ไปที่ **Settings → Pages → Build and deployment** เลือก **Deploy from a branch** → `main` / `(root)` แล้วกด **Save**
4. รอ 1–2 นาที แล้วเปิด `https://<ชื่อบัญชี>.github.io/timetable/`

ครั้งแรกที่ครูซึ่งมีสิทธิ์แก้ไขเข้าสู่ระบบ ระบบจะบันทึกตารางเริ่มต้น (จาก PDF ภาคเรียนที่ 2/2569) ขึ้นฐานข้อมูลให้อัตโนมัติ

## การใช้งานประจำวัน

- **ดูตาราง** เปิดลิงก์ได้เลย ไม่ต้องเข้าสู่ระบบ
- **แก้ไข** กดปุ่มสถานะมุมขวาบน (ดูอย่างเดียว · เข้าสู่ระบบ) แล้วเข้าสู่ระบบด้วยบัญชีที่ผู้ดูแลเพิ่มไว้ ระบบบันทึกอัตโนมัติ ปุ่มจะแสดงว่า *ออนไลน์ · บันทึกแล้ว*
- **ถ้ามีคนแก้ไขพร้อมกัน** ระบบจะเตือน แล้วให้เลือกว่าจะโหลดข้อมูลล่าสุด หรือบันทึกทับด้วยข้อมูลของตัวเอง
- **กู้คืนเวอร์ชันเก่า** กดปุ่มสถานะ → ประวัติการแก้ไข → กู้คืน

### จัดตารางอัตโนมัติ

1. เลือกครูคนเดียวหรือหลายคน
2. เลือกโหมด
   - *จัดใหม่ทุกคาบที่ไม่ล็อก* : จัดคาบสอนเดิมของครูที่เลือกใหม่ ถ้าติ๊ก "คงเวลาเดิมให้มากที่สุด" ระบบจะย้ายเฉพาะคาบที่จำเป็น
   - *จัดเฉพาะภาระงานที่ยังไม่ลงตาราง* : หาเวลาให้วิชาที่เพิ่มใหม่
3. ตั้งเงื่อนไข
   - **ทั่วไป:** คาบพักกลางวันของ ม.ต้น และ ม.ปลาย · สอนไม่เกินกี่คาบต่อวัน · สอนติดกันไม่เกินกี่คาบ · วิชาเดียวกันไม่ซ้ำวัน · หลีกเลี่ยงคาบ 8
   - **รายบุคคล:** เวลาที่ครูไม่ว่าง และจำนวนคาบสูงสุดต่อวัน
4. กด **จัดตาราง** ดูตัวอย่าง (ช่องที่มีกรอบสีทองคือเวลาใหม่) แล้วกด **ใช้ผลลัพธ์นี้**

คาบกิจกรรมและคาบที่ **ล็อก** ไว้ (ติ๊กในหน้าแก้ไขคาบ) จะไม่ถูกย้าย ระบบจะไม่จัดให้ครู ชั้นเรียน หรือห้องชนกัน และคาบสอนร่วมจะลงในเวลาที่ครูทุกคนในคาบว่างตรงกัน

### ขึ้นภาคเรียนใหม่

แก้ `termId` ใน `config.js` เช่น `'2570-1'` ระบบจะสร้างตารางของภาคเรียนใหม่แยกจากของเดิม ข้อมูลภาคเรียนเก่ายังอยู่ครบ จากนั้นนำเข้าข้อมูลที่ **จัดการข้อมูล → สำรอง / กู้คืน** หรือใช้ **เพิ่มคาบจำนวนมาก**

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ
config.js             ค่าการเชื่อมต่อ Supabase
css/app.css           รูปแบบหน้าจอและการพิมพ์
js/core.js            ข้อมูลตั้งต้นจาก PDF และการตรวจคาบชน
js/app.js             ตาราง การแก้ไข ลากวาง และจัดการข้อมูล
js/shared.js          การตั้งค่าที่ใช้ร่วมกัน
js/summary.js         สรุปท้ายตารางและหน้าสรุปข้อมูล
js/cover.js           สอนแทน แลกคาบ และคาบตอบแทน
js/auto.js            จัดตารางอัตโนมัติ
js/export.js          พิมพ์ PDF และดาวน์โหลด Excel
js/cloud.js           เชื่อมต่อ Supabase เข้าสู่ระบบ และประวัติเวอร์ชัน
supabase/schema.sql   โครงสร้างฐานข้อมูลและสิทธิ์การเข้าถึง
```

ถ้ายังไม่ได้ใส่ค่าใน `config.js` ระบบยังใช้งานได้ แต่ข้อมูลจะเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
